# Keyra

A lightweight password manager for Android 11 and later, built around the KeePass KDBX database format. Supports synchronization via WebDAV and Android's system file picker, plus autofill in Android apps and supported web browsers.

Built with Kotlin and Android Views; [Kotpass](https://github.com/keemobile/kotpass) handles KDBX files.
