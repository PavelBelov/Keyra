# Database icons

Temporary set of 69 database icons, indexed by KDBX icon ID (0–68).
The SVGs in `icons/` are intended to be replaced with the final artwork.

Android PNG resources are generated at 112px (28dp, xxxhdpi).
To regenerate, follow the two commands at the beginning of
`scripts/generate-vault-icons.cjs`. The converter is only a development tool;
it adds no runtime dependency to the app.
